## 五、顺带发现的风险与建议（非删除项）

1. **【高危】`.gitignore` 未忽略 `.env`**：密钥可能被提交。请按 1.4 立即补全。
2. **【中危】JWT 密钥复用 `DASHSCOPE_API_KEY`**（`app/utils/security.py:26`）：建议改用独立的 `SECRET_KEY` 环境变量。
3. **【低】`pyproject.toml` 把 `pytest` 列为运行时依赖**：应移到 `[tool.uv]` 的 dev 依赖，避免生产镜像装测试包。
4. **【低】`use_llm_reranker=False` 形同虚设**（`rag_tools.py`）：`pipeline.py` 仍无条件调用 `LLMReranker.rerank()`，重排每次都调 LLM，与标志语义不符；要么真正按标志开关，要么删掉该标志。
5. **【低】`reranker.py` 模型硬编码 `qwen-turbo`**：与全局 `QWEN_MODEL_NAME` 不一致，建议统一从 `settings` 读取。
6. **【低】`query_optimizer.py` 模型硬编码 `qwen3.8-flash`**：与 `config.py` 的 `qwen3.7-flash` 不一致。
