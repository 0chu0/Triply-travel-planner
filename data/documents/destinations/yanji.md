# 延吉旅游攻略

## 城市概况

延吉市是吉林省延边朝鲜族自治州首府，位于东北东部、长白山北麓，与朝鲜隔图们江相望。这里朝鲜族文化氛围浓厚，街巷招牌多为朝汉双语，饮食、服饰、节庆和城市生活都带有鲜明的边疆民族特色。延吉节奏悠闲，美食密集，是体验朝鲜族风情、边境城市风光和东北烟火气的热门目的地。

**最佳旅游季节**：6\-9 月（夏季凉爽，适合避暑）、10 月（秋景漂亮）；冬季可体验冰雪和朝鲜族年味。

**推荐游玩天数**：2\-3 天

## 必游景点

### 延边大学周边街区

**简介**：延吉最具代表性的城市街区之一，校园周边年轻气息浓厚，奶茶店、咖啡店、烤肉店和朝鲜族风格小店密集，适合散步拍照。

**门票**：免费

**开放时间**：街区全天开放

**游览建议**：

- 建议游览时间：1\-2 小时

- 适合傍晚到夜间逛，灯光和街景更有氛围

- 很多店铺有朝鲜族特色装修，适合拍照打卡

- 周边美食多，建议边逛边吃

**交通**：市区内打车或公交可达，多数景点到延大周边都比较方便。

### 朝鲜族民俗园

**简介**：展示朝鲜族传统民居、生活习俗和节庆文化的主题园区，可体验传统服饰、拍照和民俗活动。

**门票**：通常免费或低收费，具体以园区当天公告为准。

**开放时间**：一般为 9:00\-18:00，部分活动按场次安排。

**游览建议**：

- 建议游览时间：2\-3 小时

- 可以租朝鲜族传统服饰拍照，建议提前选好店铺

- 上午光线好，适合拍人像；下午氛围更轻松

- 节假日人多，建议早到

**交通**：市区打车约 15\-25 分钟，也可乘坐公交前往。

### 图们江边境景区

**简介**：延吉周边代表性边境景观，可远眺图们江和对岸城市风貌，感受中朝边境的独特地理氛围。

**门票**：多数观景区免费，部分体验项目另收费。

**开放时间**：全天可游览，建议白天前往。

**游览建议**：

- 建议游览时间：半天

- 适合与珲春、防川等边境线路安排成一日游

- 边境地区注意标识，不要越界、不要随意拍摄军事设施

- 晴天视野更好，建议上午出发

**交通**：延吉到图们建议包车或参加一日游，公共交通相对折腾。

### 长白山北景区

**简介**：长白山是东北第一名山，拥有天池、瀑布、温泉、林海和火山地貌，从延吉出发适合安排一日或两日游。

**门票**：景区门票约 105 元，环保车、倒站车等另收费。

**开放时间**：一般为 7:00\-17:00，冬季会缩短。

**游览建议**：

- 建议游览时间：1 天

- 天池受天气影响大，出发前查景区开放公告

- 山区温差明显，夏季也建议带外套

- 北坡经典路线：天池 → 长白瀑布 → 聚龙泉 → 地下森林

- 节假日建议早入园，避开排队高峰

**交通**：延吉到长白山自驾约 3 小时，也可参加景区直通车或一日游团。

### 西市场 / 东华街周边

**简介**：延吉本地人生活气息很强的商圈，小吃、甜品、烤肉、汤饭和朝鲜族食品店集中，适合边逛边吃。

**门票**：免费

**开放时间**：店铺一般 10:00\-22:00 左右。

**游览建议**：

- 建议游览时间：2\-3 小时

- 适合安排在晚餐前后，吃完烤肉再逛甜品店

- 可尝试打糕、米肠、紫菜包饭、朝鲜族冷面等小吃

- 晚上比白天更热闹

**交通**：市区内步行、打车或公交都方便。

### 帽儿山国家森林公园

**简介**：延吉市区附近的城市山林，登山步道轻松，山顶可俯瞰延吉城区和远处山脉。

**门票**：免费

**开放时间**：全天开放，建议白天登山。

**游览建议**：

- 建议游览时间：2 小时

- 适合早上去，空气好、人少

- 山路以台阶和步道为主，穿舒适鞋子

- 雨后山路湿滑，注意安全

**交通**：市区打车约 10\-20 分钟。

## 特色美食

### 必吃美食清单

1. **朝鲜族烤肉**：延吉招牌美食，推荐烤五花肉、烤肥牛、烤牛肠，人均约 80\-150 元。

2. **冷面**：酸甜爽口，面条筋道，适合夏天吃，一般 15\-25 元 / 碗。

3. **拌饭**：石锅拌饭或朝鲜族拌饭，锅巴香、配料丰富，约 20\-35 元。

4. **部队锅**：年糕、拉面、芝士、香肠等煮在一起，适合多人分享，人均约 60\-100 元。

5. **米肠**：朝鲜族特色糯米肠，可蘸料吃，一般 15\-30 元。

6. **打糕**：软糯香甜，现做现吃口感最好，约 10\-20 元。

7. **紫菜包饭**：适合当小吃或伴手，约 10\-20 元。

8. **辣炒年糕**：街头常见小吃，甜辣入味，约 10\-15 元。

9. **牛肠锅 / 肥肠锅**：延吉夜间人气美食，适合下酒，人均约 70\-120 元。

10. **咖啡甜品**：延吉咖啡店很多，适合午后休息，人均约 30\-60 元。

### 美食街区

- **延大网红墙周边**：店铺密集，适合拍照、喝咖啡、吃烤肉。

- **西市场 / 东华街**：本地生活气息强，小吃和家常菜多。

- **发展村 / 梨花路一带**：烤肉、汤饭、咖啡店集中，游客和本地人都多。

- **夜间美食街**：适合吃夜宵，烤肉、牛肠、部队锅、啤酒屋集中。

## 住宿建议

### 推荐区域

1. **延大 / 网红墙区域**：

    - 优势：城市氛围好，餐饮多，拍照方便，晚上热闹。

    - 价格：150\-400 元 / 晚。

    - 适合：首次来延吉、喜欢逛吃拍照的游客。

2. **西市场 / 市中心区域**：

    - 优势：交通方便，吃饭选择多，去各街区都近。

    - 价格：120\-350 元 / 晚。

    - 适合：想节省通勤时间的游客。

3. **火车站 / 客运站周边**：

    - 优势：交通便利，适合转车或短途停留。

    - 价格：100\-300 元 / 晚。

    - 适合：赶车、预算型游客。

## 实用信息

### 交通

- **市内交通**：延吉市区不大，打车通常起步价即可到达很多核心街区；公交也覆盖主要景点。

- **城际交通**：延吉有高铁站和客运站，往返长春、图们、珲春等地较方便。

- **长白山交通**：建议包车、参加一日游或住一晚，不建议当天往返太赶。

- **边境游览**：图们、珲春、防川建议安排成半日或一日游。

### 温馨提示

1. **语言**：延吉很多店铺有朝汉双语标识，日常交流普通话基本没问题。

2. **气候**：东北早晚温差大，夏季也建议带薄外套；冬季寒冷，注意保暖。

3. **饮食**：朝鲜族美食偏酸辣、生冷，肠胃弱的人建议少量尝试，备点肠胃药。

4. **边境安全**：不要越界，不要拍摄军事设施和口岸敏感区域。

5. **预订**：节假日和暑期住宿、长白山门票建议提前安排。

6. **伴手礼**：可买朝鲜族辣酱、打糕、紫菜包饭相关食品、东北木耳等。

## 推荐行程

### 3 日游经典行程

**Day 1**：抵达延吉 → 延大网红墙 → 西市场逛吃 → 晚上烤肉
**Day 2**：图们江边境景区 → 珲春 / 防川一日游（可选）→ 回到延吉吃夜宵
**Day 3**：帽儿山国家森林公园 → 朝鲜族民俗园 → 返程

### 长白山 \+ 延吉 4 日游

**Day 1**：抵达延吉，市区逛吃
**Day 2**：延吉 → 长白山北坡一日游
**Day 3**：图们 / 珲春边境一日游
**Day 4**：民俗园 → 延大周边 → 返程

**预估花费**（人均）：

- 门票：约 100\-200 元（市区景点为主）；去长白山约 300\-500 元

- 住宿：约 400\-800 元（2\-3 晚）

- 餐饮：约 400\-700 元

- 交通：约 200\-500 元（含市区及周边包车）

- 总计：约 1100\-2200 元（经济型）
